# Hardware Deployment Guide — PAI-IR

## Supported Hardware Platforms
- **Compute**: NVIDIA Jetson AGX Orin / Orin Nano / x86 Industrial PC
- **AMR Chassis**: Differential Drive Industrial AMR Base
- **Manipulator**: 6-DOF / 7-DOF Robotic Arm (Parallel Gripper End-Effector)
- **Perception**: 3D LiDAR (25m range) + RGB-D Stereo Depth Camera + 6-Axis IMU
