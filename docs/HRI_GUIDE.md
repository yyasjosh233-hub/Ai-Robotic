# Human-Robot Interaction (HRI) Guide — PAI-IR

## Gestures Mapped
- `WAVE`: Greeting trigger
- `STOP`: Immediate safe stop
- `POINT`: Pointing ray vector calculation to select industrial targets
- `THUMBS_UP`: Task confirmation
- `THUMBS_DOWN`: Task rejection
- `FOLLOW_ME`: Dynamic follow mode
- `COME_HERE`: Navigates AMR to human coordinates
- `EMERGENCY`: Software E-Stop
