# ROS 2 Integration Guide — PAI-IR

## Packages
- `pai_bringup`: Launch files for hardware & simulation
- `pai_navigation`: Nav2 costmap & dynamic human obstacle avoidance nodes
- `pai_perception`: YOLOv8 & MediaPipe ROS 2 camera drivers
- `pai_hri`: Voice & gesture action servers
- `pai_manipulation`: MoveIt 2 6-DOF arm trajectory planner
- `pai_inspection`: OpenCV CV quality inspection service
- `pai_planner`: Task planner state machine node
- `pai_safety`: Lifecycle node enforcing hardware E-Stop
- `pai_simulation`: Gazebo / Isaac Sim bridges
